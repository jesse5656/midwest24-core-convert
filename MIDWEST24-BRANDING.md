# Midwest24 Core Convert Branding

This repository is the Midwest24-branded deployment fork of ConvertX.

## Baseline

- Upstream: https://github.com/C4illin/ConvertX
- Upstream baseline: v0.18.0
- Midwest24 canonical branding repository: https://github.com/jesse5656/midwest24-site
- Canonical branding commit: 5b76f7a226e1b15b324b957e342263f6d0262729
- Public service: https://convert.midwest24.com

## Branding changes

The Midwest24 deployment changes only product identity and presentation:

- Midwest24 Core Convert product logo in the application header
- Midwest24 Core Convert favicon and application icons
- Midwest24 Core Convert browser titles
- Midwest24 attribution in the footer
- upstream ConvertX attribution and version retained
- public link to this modified source retained

Conversion behavior and the /app/data persistence model are unchanged by this
branding patch.
